# DevCleaner

Приложение на SwiftUI для macOS 14+, которое чистит диск от того, что копится при разработке:
мобильной (Xcode, симуляторы, Gradle, Android), веб (npm/yarn/pnpm/bun, браузеры для тестов, Docker)
и при работе AI-агентов (модели, кэши uv/pip, логи редакторов и агентов).

## Запуск

```bash
cd DevCleaner
swift run                 # быстрый запуск
open Package.swift        # или открыть в Xcode и нажать ⌘R
./scripts/build-app.sh    # собрать build/DevCleaner.app
swift test                # тесты
```

Приложение не в песочнице: ему нужен доступ к `~/Library`, `~/.gradle` и т. п.
Для очистки Корзины и бэкапов iOS выдайте собранному `.app` доступ в
*Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску*.

## Что умеет

- **Сводка**: сколько можно освободить без риска, разбивка по категориям и советы: безопасные кэши, артефакты в проектах, то, что требует внимания.
- **Глобальные кэши**: около 60 известных мест, каждое с описанием и пометкой
  «безопасно» или «осторожно». Безопасное восстановится само при следующей сборке
  или установке. «Осторожно» — это модели, эмуляторы, архивы, история сессий агентов.
- **Команды** вместо удаления там, где так правильнее: `xcrun simctl delete unavailable`,
  `pnpm store prune`, `docker system prune -af`, `go clean -modcache`. PATH берётся из вашего
  login shell (zsh, bash, fish), включая `.zshrc` и `config.fish`. Если инструмента нет,
  цель помечается «не установлено». У команд есть таймаут.
- **Артефакты сборки в проектах**: обходит выбранную папку (по умолчанию `~/Projects`, `~/Developer`
  или `~/Code`) и находит `node_modules`, `.next`, `Pods`, `.build`, `build`, `target`, `.venv`,
  `__pycache__`, `.yarn/cache`, `cmake-build-*`, `bin`/`obj` .NET и другие. Каждое правило срабатывает
  только при маркере проекта рядом (`package.json`, `Podfile`, `Cargo.toml`, `mix.exs`…).
  Папки инструментов в домашней папке (`~/.nvm`, `~/.local`, `~/.config`, `~/.cargo` и т. д.)
  не обходятся, чтобы не задеть глобальные пакеты. Результаты появляются по ходу поиска, его можно
  остановить. Активность проекта — дата самого свежего файла, без артефактов и `.git`.
- **Ничего не выбирается само**: перед удалением показывается полный список выбранного.
- **Режим «В Корзину»** вместо безвозвратного удаления. Сама Корзина всегда чистится безвозвратно.
- **Журнал**: что удалено, тексты всех ошибок и итог по изменению свободного места на диске.
  Журнал и настройки сохраняются между запусками.

## Защита

`Cleaner` удаляет только внутри домашней папки и отказывается удалять её
корневые каталоги (`~/Library`, `~/Documents`, `~/.ssh`, `~/.claude` и т. д.).
Перед удалением всегда показывается подтверждение.

## Как добавить свою цель

Допишите элемент в `Sources/DevCleaner/Models/Catalog.swift`:

```swift
.init(id: "my.cache", name: "Мой кэш",
      detail: "Что это и восстановится ли само.",
      category: .agents,
      paths: ["~/.cache/my-tool"])
```

Для команды укажите `action: .command("my-tool prune")`. Если команда начинается не с имени
нужной программы, добавьте `requires: "my-tool"`. Последний компонент пути может быть шаблоном
`Prefix*`.
Для проектных артефактов добавьте правило в `ProjectScanner.rules`.

## Структура

```
Sources/DevCleaner/
  DevCleanerApp.swift        точка входа
  Models/                    CleanupTarget, Catalog (список путей), ProjectArtifact, DiskInfo
  Services/                  SizeCalculator, Cleaner, ProjectScanner, Shell, FullDiskAccess, Paths
  Store/                     CleanerStore (@Observable-состояние), сохранение журнала и настроек
  Views/                     сайдбар, сводка с полосой занятого места, плашка выбора, списки, таблица проектов, журнал, подтверждение
Tests/DevCleanerTests/       swift test: удаление, сканер, правила, размеры, shell, каталог
```
